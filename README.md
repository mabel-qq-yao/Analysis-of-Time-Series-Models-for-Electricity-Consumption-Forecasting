Objectives of Time Series Analysis: Modeling and Forecasting

1- set up a probability model to represent data; 

2- estimate parameters in the model;

3- check the goodness of the model fit for the data; 

4- use the fitted model to enhance our understanding of the mechanism generating the series; 

5- once the probability model has been established, we may use it to summarize the data or forecast (predict) the future values, etc.
